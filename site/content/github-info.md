## Recent updates

### From the GitHub Changelog

Source: [GitHub Changelog](https://github.blog/changelog/), October 2026.

- **Stacked pull requests are generally available (Oct 6).** Break big changes into a chain of small, reviewable pull requests.
- **GitHub Actions workflow lockfiles in public preview (Oct 14).** Worth a look if you want more predictable workflow runs.
- **AI Scan for pull requests and agentic autofix for code scanning alerts are generally available (Oct 15).** Security feedback and suggested fixes where you already review code.
- **Local sandboxing for GitHub Copilot is generally available (Oct 7).** Safer local agent runs.
- **Triage role users or higher can now archive pull requests (Oct 8).** Handy for keeping busy repositories tidy.
- **Heads-up:** selected Copilot models are being deprecated in mid-November (Oct 15), and macOS 14 Actions runner images are retired (Oct 1). Check your model choices and `runs-on` labels.

### From Awesome Copilot workflows

Source: [Awesome Copilot workflows](https://awesome-copilot.github.com/workflows/) (redirects to the `workflows` folder of `github/awesome-copilot`).

Ready-made agentic workflow examples to learn from and adapt:

- `daily-issues-report`: a daily summary of repository issues.
- `ospo-org-health`, `ospo-stale-repos`, `ospo-contributors-report`, `ospo-release-compliance-checker`: open source program office health and compliance reports.
- `relevance-check` and `relevance-summary`: checking and summarizing whether content is still relevant.
- `weekly-comment-sync`: a weekly comment sync routine.
